# Open Calculation Platform

Free engineering calculations with live math and units, on Windows and Android.

- **Website and guide:** https://opencalculationplatform.github.io/
- **Download:** [latest release](https://github.com/opencalculationplatform/ocp/releases/latest): Windows setup, portable zip, Android APK
- **Directory of components and tables:** https://github.com/opencalculationplatform/ocp-directory
- **Questions and bug reports:** [open an issue](https://github.com/opencalculationplatform/ocp/issues)

This repository holds OCP's public releases.
