# Open Calculation Platform

Free engineering calculations with live math and units, on Windows and Android.

- **Website:** https://alirezakord.github.io/ocp/
- **Download:** [latest release](https://github.com/AlirezaKORD/ocp/releases/latest): Windows setup, portable zip, Android APK
- **Directory of components and tables:** https://github.com/AlirezaKORD/ocp-directory
- **Questions and bug reports:** [open an issue](https://github.com/AlirezaKORD/ocp/issues)

This repository holds the website and the public downloads.
