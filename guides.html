Guides

OCP grows with what engineers add to it. None of it needs programming, except Python functions.

1. Components: a worksheet as a calculation block 2. Tables: your data as functions 3. Python functions (Windows) 4. Sharing in the directory

1. Components

A component is a worksheet you can insert into any other, with a form for its inputs. Write the calculation once, then reuse it everywhere.

  1. Write the calculation as usual, with example values: w := 10 kN/m, L := 6 m, M := w·L²/8.
  2. Choose Insert › Save as component (phone: ⋮ › Save as component…).
  3. Give it a title, a category and a short description of what it calculates and its limits.
  4. For each name, choose Input (filled in by whoever uses it), Result (given back) or neither, and give it a label. The first result is the component's value for the formulas below it.
  5. Keep the worked example option on (the values and their results): OCP checks the example every time the component is saved or added, so a change that breaks it is caught.

Insert it with Insert › Components. Its form takes values (3 m) or names from the worksheet. A component can use other components, and its report shows each formula as written math, with the inputs in the units they were typed.

2. Tables

A table becomes a function every worksheet can call, by its name, a row and a column:

IPE("IPE 300", "Wpl_y")      → 628.4 cm³
Concrete("C30/37", "fctm")   → 2.9 MPa
Rebar(16, "A4")              → 804.2 mm²

Making one

Use a CSV file (as Excel saves it, with ;, , or tab) or an Excel workbook (.xlsx, its active sheet):

  • The heading row: the key column's heading, then each column with its unit in brackets: A [cm^2] or A (cm²).
  • Then one row per key: IPE 300; 53.8; 8356. Decimal commas work.
  • The table takes the file's name: IPE sections.xlsx becomes IPE_sections. A title above the heading row in Excel is left out.
Section;h [mm];A [cm^2];Iy [cm^4]
IPE 200;200;28.5;1943
IPE 300;300;53.8;8356

Bring it in with Insert › Tables › Bring in… (phone: ⋮ › Tables… › +). View shows its rows. Rows are found without spaces and in any case ("ipe300" works); columns by their name, in any case, so two columns cannot be called Iy and iy.

Picking a row

Tap a table (or Insert drop-down on Windows) to insert a drop-down of its rows, Section := "IPE 200", then write IPE(Section, "A"). Choosing another section updates every formula below.

3. Python functions

For what a formula cannot say easily (loops, iterations, a design code's procedure), write a function in Python and call it in any formula. It needs Python 3 installed on Windows; the phone does not run Python.

import math

def moment(w: "kN/m", L: "m") -> "kN*m":
    '''Mid-span bending moment of a simply supported beam.'''
    return w * L**2 / 8

def deflection(w: "kN/m", L: "m", E: "GPa" = 210, I: "cm^4" = 8356) -> "mm":
    return 5 * w * (L * 1000) ** 4 / (384 * E * 1000 * I * 1e4)
  • The unit in quotes on a parameter is the unit its number arrives in: moment(10000 N/m, 600 cm) still gets w = 10, L = 6.
  • The unit after -> is the result's unit. Without one, the result is a plain number (or a text).
  • A parameter without a unit gets SI base units, a text, or a list for a vector or matrix. A parameter with a default can be left out.
  • Top-level functions are offered; those whose name starts with an underscore, such as _helper, are left out.

Open Insert › Python functions: New from example starts a file like the one above, Read again picks up your edits, Insert call writes a call into the worksheet.

Safety: a Python function can do anything Python can, such as read files or use the network. Bring in only files you wrote or trust; OCP warns before it brings one in. Python files are not shared in the directory.

4. Sharing in the directory

The directory lists the components and tables OCP users shared. It lives in a public GitHub repository, ocp-directory.

Installing

In OCP, open Insert › Directory (phone: ⋮ › Directory…), search, and choose Install. OCP checks each download against the size and fingerprint (SHA-256) the directory lists before adding it. Update appears when a newer version of a component you have is listed.

Publishing

  1. In Components or Tables, select yours and choose Publish… (phone: its ⋮ › Publish).
  2. The first time, OCP shows a code. Open GitHub, sign in (a free account) and enter it. OCP never sees your password, and forgets the sign-in when it closes.
  3. OCP opens a pull request with your file. It is checked automatically, reviewed, and once merged it appears in everyone's directory.

A component is published only if its worked examples come out right and it has a category and a description: they are how others find it and trust it.
